# Demonstration journey

1. Open Bills, choose 2025-26, search 1960. Show official source metadata, E3SHB 1960, sponsors, amendments and historical hearings. Choose an untracked bill for the assignment journey, work starts empty.
2. Switch to Assigner. Start Tracking (or Add work assignment) → Bill Analysis → choose primary/backup/reviewer/manager → classify → deadlines → Create assignments. Note the names chosen.
3. Open the newly created analysis. Switch to Analyst and use Acting as to select the assigned primary or backup. Draft content, choose topics, flag an issue and enter issue details. Mark done and notify next.
4. Switch to Reviewer and select the assigned reviewer. My Work → Needs My Review → Review. Return with an explanation or Approve. The preparer cannot approve.
5. Switch to Manager or Assigner. Open analysis → Publish. Expand published revision and inspect audit on the review screen.
6. Edit published content as the assigned Analyst. Published — Changes Pending appears. Publish is blocked until the new content is submitted and approved; republishing retains both revisions.
7. Switch to Administrator → Legislative imports → Refresh simulated hearings. Open an affected bill and Notifications to show changed hearing, active-work flags and the import payload/history.
8. Create a fiscal note linked to an official bill. Show revenue and expenditure/FTE, the prior-product empty state and supporting document upload. Route contributors as Assigner; submit as the assigned Analyst.
9. Approve as the assigned Reviewer. For required Executive Review use Acting as to follow the sequence. Manager → Transmit to OFM FNS → View Payload — Demo Integration. The fiscal record locks and retains its receipt.
10. Use phone viewport: Approvals cards show sequential actions; the hearing page and bill workspace remain responsive. The bill summary includes fiscal totals, work statuses and Executive Review progress; see traceability for remaining details.

Reset demo restores 250 official bills, empty workspaces and simulated meetings at 20, 48, 70 and 96 hours. Refresh reloads the JSON fixtures and discards session changes.
